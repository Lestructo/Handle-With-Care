# Handle-With-Care

Final group project for CS 4053/5053 Computer Graphics. A first-person physics puzzle game developed in Unity, demonstrating core graphics concepts including Phong-based lighting and shading, texture mapping, 3D transformations, collision detection, and real-time interaction. Features a custom URP outline shader, a spotlight-triggered door system, physics-based crate manipulation, and a full UI with pause menu, game timer, and victory screen.

# Controls

```
WASD: Move
Space: Jump
Left Click: Grab / Release
Right Click: Magnetize (Hold)
Scroll Wheel: Adjust grab distance
T: Pause game
```
